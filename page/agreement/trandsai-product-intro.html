Runtime Path

From message ingress to relationship depth

Short greetings can short-circuit; heavier turns route through preparation, intent, response, and quality control, while archive work stays off the first-response path.

01 · INGEST

Realtime intake

Client messages enter through WebSocket and hit Redis before asynchronous persistence handles the durable layer.

02 · ROUTE

Light / heavy routing

LangGraph path selection lets low-complexity turns move quickly while emotional or long-form cases go deeper.

03 · RESPOND

Pipeline v2 response flow

Preparation, must-answer logic, response generation, and rewrite checks keep the reply useful without flattening personality.

04 · ARCHIVE

Background relationship build-up

Facts, summaries, relation-card updates, and persona evolution are archived asynchronously so continuity deepens over time.

Stack

Integrated frontend and backend for a production companion product

Agent pools, per-user turn locking, async workers, local caches, and multi-surface UX make this a product system, not a thin interface over a model.

Backend

  • APIFastAPI, Uvicorn, and Starlette WebSocket
  • AgentLangGraph / LangChain with tiered LLM roles for respond, inner, and archive
  • DataPostgreSQL, Redis, and ChromaDB for persistence, chat hot path, and memory retrieval
  • WorkersAgent queue, archive workers, and chat flush workers
  • MediaAvatar and Moments image generation plus object storage

Frontend

  • Appuni-app, Vue 3, Pinia, and vue-i18n
  • ChatVirtualized long threads, emoji input, date separators, and typing-state behavior
  • SocialMoments feed, companion discovery, and creation flows
  • PerfMessage, companion, and home caching with staggered reconnect handling
  • LocaleMulti-language UI aligned with companion language support
