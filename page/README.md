# `page/` — static frontends (example layout)

| 目录 | 用途 |
|------|------|
| `frontend/` | 主站用户端静态资源 |
| `kaya/` | 马甲包静态资源示例 |
| `admin/` | 管理后台静态资源 |
| `agreement/` | 隐私政策 / 用户协议 HTML |
| `file/` | 杂项静态（如域名验证） |
| `cert/` | **自备证书**，仓库内无真实密钥 |

本地可用任意静态服务器打开，或用仓库根目录的 Nginx 示例反代到后端 `8000`。

API 地址、域名请在前端构建配置 / 运行环境里自行填写，本目录只提供已构建的静态示例。
